# AI SkillHub Backend

NestJS REST API untuk data Skill. Struktur memakai Entity, Service, Controller, dan DTO.
Data disimpan dalam array di memori; restart server mengembalikan empat skill awal.

## Jalankan

Dari folder ini:

```bash
npm install
npm run start:dev
```

- API: http://localhost:3000/api/skills
- Swagger UI / REST client: http://localhost:3000/docs
- Pengujian otomatis: npm run test:e2e
- Build: npm run build

Baca bagian Minggu 9 di README repository untuk rincian MVC, validasi, endpoint, dan screenshot.
